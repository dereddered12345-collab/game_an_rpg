ASHEN REALMS — мобильная PWA RPG

СОДЕРЖИМОЕ
- index.html — интерфейс игры
- style.css — оформление
- game.js — игровой цикл, бои, предметы, прогресс и сохранение
- manifest.webmanifest — параметры установки
- sw.js — офлайн-кэш
- icon.svg — иконка приложения

КАК ЗАПУСТИТЬ
1. Распакуй архив.
2. Загрузи содержимое папки на статический HTTPS-хостинг (например, GitHub Pages или Netlify).
3. Открой полученную HTTPS-ссылку в Chrome на Android.
4. В меню Chrome выбери «Установить приложение» или «Добавить на главный экран».

ВАЖНО
- Для установки PWA нужен HTTPS (либо localhost для тестирования).
- Прогресс хранится в localStorage браузера на этом устройстве. Не очищай данные сайта, иначе сохранение может пропасть.
- Игра не требует аккаунта и не имеет лимита ходов.
- Это первая играбельная версия-прототип; облачной синхронизации и резервного экспорта сохранения пока нет.
